## Native contracts

The birth entry consumes eight raw 64-bit register arguments, from A0 through
T3. Its Unity counterpart has nine managed formals and different output
containers. The five routines at `001FE170`, `001FE880`, `001FEB28`, `001FEC40`
and `001FF4D0` are void. Their incidental V0 contents are not defined results.
Each continuation records its own return ownership, preserving the preceding
birth return when a void follow-up runs.

Real descriptor, skill, inheritance and EXP tables initialize both executions.
The full path requires 128 KiB of stack backing; observed native SP reaches
`0064D780`. The C resolver owns the upper 8 KiB separately, so initialization
respects that split. Stack balance is checked; full private-frame byte equality
is outside this semantic comparison.

The diagnostic branch uses a genuinely initialized buffered FILE, original
locale/digit/padding bytes and the actual formatter. Fifty-five original birth
cases write 2,750 diagnostic bytes. This establishes the buffered path, without
claiming physical console output or completion of arbitrary stdio devices.

An unsupported rank direction can leave the scan step at zero. With an excluded
interior candidate, the original loop can repeat without progress under the
unchanged input world. The
[bounded observation and source proof](fusion-core-rank-direction-divergence.json)
retain this behavior. The recovered routine has no artificial iteration cap.
All 36 authored unsupported-direction returning cases remain in the base suite;
their candidates meet the original eligibility checks.

The edge suite distinguishes retail values from raw-field guards. IDs 40 and 41
are race-8 Mitama for the reversed-parent copy path; ID 36 is race-7 Spirit.
The raw initial level 256 case exercises the integer level clamp outside the
retail 0..255 domain. It does not stand in for a floating-point conversion test.

## Remaining scope

The [coverage frontier](fusion-core-coverage-frontier.json) records the base
capture's 44 unvisited non-delay instruction addresses. The separate 12 cases
reach 31 of those addresses; the independent results review qualifies the
remaining 13 against immutable tables and input-domain constraints. Delay-slot
coverage is not separately sampled. All ten previously missed
sorter fallback addresses are reached by the base suite's twelve sorter cases.

The proof covers finite returning inputs, ordinary RAM and immutable tables,
defined results, actual completion, callback order, Status, FCSR value/condition
and CPU primitives. Complete volatile banks, upper 128-bit register effects,
HI/LO, arithmetic FCSR exception flags, all private-frame bytes, timing,
physical hardware and gameplay remain outside this proof. The observer catches
traps owned by the new source; it does not establish arbitrary nested canonical
trap handling. Full executable recovery remains open.
