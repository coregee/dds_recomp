# dds_recomp

Source-level reconstruction of Atlus PS2 games built on the DDS3 engine.

| Game | Folder | State |
|---|---|---|
| *Shin Megami Tensei III: Nocturne* (US, `SLUS_209.11`) | [nocturne/](nocturne/README.md) | active |
| *Digital Devil Saga* (US, `SLUS_209.74`) | [digital_devil_saga/](digital_devil_saga/README.md) | parked: disc extraction and early Ghidra notes |

Disc images, extracted game files and Ghidra databases stay local and are
ignored by git. Each game's README explains how to recreate them.
